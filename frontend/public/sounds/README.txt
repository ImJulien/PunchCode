Paste audio files into this folder using these filenames:

punch.wav         Keypunch typing sound for each punched character.
paper-enter.wav   Paper/card movement when ENTER releases a card.
paper-enter.wav   Paper movement when a card is released or an inspected card is scrapped.
paper-deck.wav    Paper movement when the entire deck is scrapped.
hover.wav         Short sound when the pointer enters a button.
button.wav        Short sound when a button is pressed.
compile.mp3       Compile button sound.
music.mp3         Optional looping background music.

The existing machine effects use these additional optional filenames:
feed.wav, reader.wav, printer.wav, and lock.wav.

Missing optional files are ignored by the browser until you add them.
